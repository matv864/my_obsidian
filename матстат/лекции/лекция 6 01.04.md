# Критерий хи-квадрат
### область применения
Критерий хи-квадрат - используется для анализа данных, измеренных по шкале наименования. Особенно полезен для проверки гипотез о равенстве вероятностей попадания объектов в
категории.

### таблица 2x2
Результаты измерений для двух групп (экспериментальной и контрольной) могут быть представлены в виде таблицы

| Группа      | $I_k$ | $II_k$ |
| ----------- | ----- | ------ |
| Эксперимент | $э_1$ | $э_2$  |
| Контроль    | $к_1$ | $к_2$  |
$n_э=э_1+э_2$
$n_к=к_1+к_2$
$N=n_э+n_к$

### Расчёт критерия
$$x^2_{расчёт} = \frac{N(э_1к_2-э_2к_1)^2}{n_эn_к(э_1+к_1)(э_2+к_2)}$$
##### критическое значение:
$$x^2_{табл}=(a,k=1)$$
##### __правило принятия решения__:
Если $x^2_{расчёт} > x^2_{табл}$, то различие между результатами считается неслучайным
```ad-note
title: Критерий хи-квадрат не рекомендуется использовать при:

Критерий хи-квадрат не рекомендуется использовать при:
- $N < 20$
- $min(э_1, э_2, к_1, к_2) < 5$
```

```ad-note
title: Если хотя бы одна из величин находится в диапазоне [5, 10], применяется корректировка:

$$x^2_{расчёт} = \frac{n((э_1к_2-э_2к_1)-\frac{n}{2})^2}{n_эn_к(э_1+к_1)(э_2+к_2)}$$
```

```ad-example
title: пример

| Группа      | Выполнено | Не выполнено | Итого |
| ----------- | --------- | ------------ | ----- |
| Эксперимент | 15        | 10           | 25    |
| Контроль    | 13        | 12           | 25    |
| Итого       | 28        | 22           | 50    |
Расчётное значение:
$$x^2_{расчёт} = \frac{50(15*12-10*13)^2}{25*25*28*22} \approx 0.032$$
Критическое значение (α = 0.05, k = 1):
$$x^2_{табл}=3.8$$
Вывод: $x^2_{расчёт} < x^2_{табл}$, следовательно, нет оснований считать одну методику более эффективной.
```
### таблица с >2 категорий

| Группа      | $I_k$ | $II_k$ | ... | $P_k$ |
| ----------- | ----- | ------ | --- | ----- |
| Эксперимент | $э_1$ | $э_2$  | ... | $э_p$ |
| Контроль    | $к_1$ | $к_2$  | ... | $к_p$ |
$n_э=\sum^{p}_{i=1}{э_i}$
$n_к=\sum^{p}_{i=1}{к_i}$
### Расчёт критерия
$$x^2_{расчёт} = \frac{1}{n_эn_к}\sum^{p}_{i=1}\frac{(n_эк_i-n_кэ_i)^2}{э_i+к_i}$$
##### критическое значение:
$$x^2_{табл}=(a,k=p-1)$$
```ad-example
title: пример


| Группа      | $I_k$ | $II_k$ | $III_k$ | Итого |
| ----------- | ----- | ------ | ------- | ----- |
| Эксперимент | 40    | 35     | 25      | 100   |
| Контроль    | 20    | 45     | 35      | 100   |
| Итого       | 60    | 80     | 60      | 200   |


Расчётное значение:
$$x^2_{расчёт} = \frac{1}{100*100}\sum^{3}_{i=1}\frac{(100*к_i-100*э_i)^2}{э_i+к_i} = 9.58$$
Критическое значение (α = 0.05, k = 2):
$$x^2_{табл}=6$$
Вывод: $x^2_{расчёт} > x^2_{табл}$, следовательно, различия значимы.
```

# Корреляционно-регрессионный анализ
### Основные понятия
##### Виды взаимосвязей
1. ***Функциональная связь***: каждому значению одной переменной соответствует строго определённое значение другой.
2. ***Корреляционная связь***: изменение одной переменной приводит к изменению средней другой переменной (Корреляция).
##### Классификация связей
- По аналитическому виду:
	- Линейные связи.
	- Нелинейные связи.
- По направлению:
	- Прямые (положительные): зависимая переменная увеличивается с ростом факторного признака.
	- Обратные (отрицательные).
- По силе:
	- Сильные.
	- Слабые.

##### Задачи анализа
Задачи корреляционно-регрессионного анализа сводятся к измерениями тесноты связи между варьирующимися признаками, определению неизвестных причинных связей и оценке факторов, оказывающих наибольшее влияние на результативный признак

Основные задачи корреляционно-регрессионного анализа:
1. Установить форму зависимости между переменными.
2. Определить функцию регрессии.
3. Использовать уравнение регрессии для оценки неизвестных значений зависимой переменной.
